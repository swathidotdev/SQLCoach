# SQLCoach
## SQL Query Performance Analyzer & Index Advisor
### 1. Project Overview
SQLCoach is a developer-focused CLI tool that analyzes SQL workloads, identifies database performance bottlenecks, recommends optimizations, and generates actionable performance reports.

The goal is to help developers and database engineers understand why SQL queries are slow and provide clear recommendations without manually analyzing complex execution plans.

SQLCoach acts as a performance coach for SQL databases.
